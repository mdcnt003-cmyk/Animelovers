Laporan Keamanan Arsitektur Web (OWASP Top 10)

Status verifikasi pertahanan aplikasi terhadap 10 ancaman siber kritikal menurut standar Open Web Application Security Project.

A01:2021 - Broken Access Control

Verifikasi token JWT HS256, kontrol hak akses bookmark per user ID, isolasi sesi.

A02:2021 - Cryptographic Failures

Zero Hardcoded Credentials. Hashing kata sandi menggunakan Bcrypt (12 salt rounds), secret dimuat via .env.

A03:2021 - Injection (XSS, SQLi, SSRF)

Semua input divalidasi regex & disanitasi ketat. Rendering DOM menggunakan SecurityEngine.safeSetText & escape HTML.

A04:2021 - Insecure Design & DoS Protection

Rate limiting (15 req/15 min untuk auth, 300 req/15 min untuk API) + In-memory cache proxy.

A05:2021 - Security Misconfiguration

Helmet CSP (Content Security Policy) diaktifkan, X-Powered-By dinonaktifkan, nosniff & HSTS aktif.

A07:2021 - Identification & Authentication Failures

Pemeriksaan kekuatan password live (panjang, variasi karakter), pencegahan user enumeration & mitigasi timing attack.

A10:2021 - Server-Side Request Forgery (SSRF)

Backend proxy menerapkan strict whitelist domain (hanya api.jikan.moe) dan sanitasi parameter upstream.
